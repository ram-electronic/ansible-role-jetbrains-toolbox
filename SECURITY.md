# Security Policy

## Supported Versions

Only the latest [release](../../releases) is supported. There's no back-porting of fixes to
older releases.

## Reporting a Vulnerability

Please **don't** open a public issue for a security vulnerability. Instead, use GitHub's
private reporting for this repo:
[Security → Report a vulnerability](../../security/advisories/new).

This is a small role maintained on the side, so there's no formal SLA, but security reports
get priority over everything else and you'll get an acknowledgement as soon as it's seen.
Once a fix is available, it ships as a new [release](../../releases) and the advisory credits
the report (unless you'd rather stay anonymous).
